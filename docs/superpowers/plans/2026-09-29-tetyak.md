# Tetyak (Minimal Modern Terminal Tetris) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a sleek, minimal, low-footprint terminal Tetris in Rust with Ratatui and Crossterm, featuring an AppleTUI-inspired aesthetic, customizable non-guaranteed piece distribution across 3 difficulties, capped speed acceleration, spacious grid layout, live pace/blast counters, and conditional explosion animations.

**Architecture:** A clean modular Rust crate with separate modules for piece rotation & RNG (`piece.rs`), grid collision & line clearing (`board.rs`), game state, pace & stats tracking (`game.rs`), AppleTUI theme & palettes (`theme.rs`), Ratatui rendering (`ui.rs`), and an event loop (`main.rs` / `src/bin/tetris.rs`).

**Tech Stack:** Rust 2021, Ratatui 0.29, Crossterm 0.28, standard library.

## Global Constraints
- Target workspace: `/home/samyak/Projects/tetyak`
- Binary outputs installed to: `~/.local/bin/tetyak` and `~/.local/bin/tetris`
- Visual styling: Strictly NO emojis. Typography, clean borders, and double-width Unicode blocks (`██`, `░░`, `▒▒`).
- Difficulty system: 3 levels (Chill, Normal, Intense) with distinct speed caps and randomizer algorithms.
- Normal mode randomizer: No guaranteed 7-bag cycle; uses classic NES 1-history reroll algorithm.
- Line clear animation: Zero pause for 1-2 lines; 120ms freeze-frame particle flash for 3+ lines.
- Footprint: Cargo release build with LTO, strip, and panic-abort for ~1.8 MB binary and <4 MB RAM.

use ratatui::style::Color;
use crate::piece::Tetromino;

#[derive(Debug, Clone, Copy)]
pub struct Theme {
    pub accent: Color,
    pub secondary: Color,
    pub text_primary: Color,
    pub text_muted: Color,
    pub border_unfocused: Color,
    pub border_focused: Color,
    pub highlight_bg: Color,
    pub ghost: Color,
    pub flash: Color,
    pub particle: Color,
}

impl Theme {
    pub fn apple_dark() -> Self {
        Self {
            accent: Color::Rgb(250, 45, 72),      // Apple Red
            secondary: Color::Rgb(140, 140, 240), // Soft Purple
            text_primary: Color::Rgb(240, 240, 245),
            text_muted: Color::Rgb(130, 130, 140),
            border_unfocused: Color::Rgb(60, 60, 70),
            border_focused: Color::Rgb(250, 45, 72),
            highlight_bg: Color::Rgb(40, 40, 50),
            ghost: Color::Rgb(70, 70, 80),
            flash: Color::Rgb(255, 255, 255),
            particle: Color::Rgb(180, 180, 200),
        }
    }

    pub fn block_color(&self, t: Tetromino) -> Color {
        match t {
            Tetromino::I => Color::Rgb(100, 210, 255),
            Tetromino::O => Color::Rgb(255, 214, 10),
            Tetromino::T => Color::Rgb(175, 82, 222),
            Tetromino::S => Color::Rgb(48, 209, 88),
            Tetromino::Z => Color::Rgb(255, 69, 58),
            Tetromino::J => Color::Rgb(10, 132, 255),
            Tetromino::L => Color::Rgb(255, 159, 10),
        }
    }
}
